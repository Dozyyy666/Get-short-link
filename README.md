# URL Shortener (Сокращатель ссылок)

Веб-приложение для сокращения длинных URL-адресов. Позволяет создавать короткие, удобные для запоминания ссылки, отслеживать количество переходов и использовать кастомные алиасы.

## ✨ Возможности

- 🚀 Мгновенное сокращение длинных ссылок
- 🏷️ Поддержка пользовательских алиасов (например, `/my-link` вместо случайного набора символов)
- 📊 Подсчет количества переходов по каждой ссылке
- 🎨 Современный и адаптивный интерфейс (HTML/CSS/JS)
- ⚡ Быстрый и асинхронный бэкенд на FastAPI
- 📚 Автоматическая генерация API-документации (Swagger UI)

## 🛠 Стек технологий

**Бэкенд:**
- Python 3.10+
- FastAPI (веб-фреймворк)
- SQLite (база данных)
- Uvicorn (ASGI-сервер)
- Pydantic (валидация данных)

**Фронтенд:**
- HTML5, CSS3, Vanilla JavaScript

## 📁 Структура проекта

Проект использует слоистую архитектуру для разделения ответственности:

```text
url_shortener_project/
├── app/                  # Бэкенд-приложение
│   ├── api/              # HTTP-маршруты (Endpoints)
│   ├── core/             # Конфигурация и настройки
│   ├── crud/             # Логика работы с базой данных (SQL)
│   ├── schemas/          # Pydantic-модели для валидации JSON
│   ├── database.py       # Инициализация SQLite
│   └── main.py           # Точка входа FastAPI
├── static/               # Фронтенд (HTML, CSS, JS)
├── .env                  # Переменные окружения
├── run_server.py         # Скрипт для удобного запуска
└── requirements.txt      # Зависимости Python
```
## 🔌 Запуск сервера
**Способ А:**
- После клонирования репозитория запустить файл *run_server.py* - этот скрипт автоматически запустит сервер на локальном хосте
**Способ Б:**
- После клонирования репозитория написать в терминале ```uvicorn app.main:app --reload```

## 📖 Использование
1. Откройте браузер и перейдите по адресу http://127.0.0.1:8000.
2. Вставьте длинную ссылку в поле ввода.
3. (Опционально) Укажите свой короткий код в поле "Свой код".
4. Нажмите кнопку "Сократить".
5. Скопируйте полученную ссылку и используйте её!
